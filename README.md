# README.md

## 项目介绍
该项目展示由 26 个方块组成的 3*3*3 魔方（中间为空）。
提供魔方 6 面顺逆时针旋转的操作按键，支持一键打乱、基于逆推的一键复原（单步执行：下一步/上一步）。
鼠标指向对应按键时，魔方对应面会有银黄色高亮提示。

## 交互与视角
- **视角操作**：用户可以通过鼠标滚轮调整相机缩放（限制距离范围，防穿模）；可以拖动改变用户视角。
- **视角约束**：改变视角不改变默认面与方向的对应关系（比如你不能让 U 变成 R）。
- **悬停高亮**：鼠标移入转动按钮时，对应面的 9 个小方块加荧黄色描边/高亮；移出后立即复原；不干扰正在进行的转动动画。

## 六个面的字母按键操作
U = 上（Up）    D = 下（Down）
L = 左（Left）  R = 右（Right）
F = 前（Front，相机初始正对的那面）
B = 后（Back）
字母后面加 ' 表示逆时针，例如 R'

## 打乱规则
- 用户输入 n（默认 20，限制 1~30）。
- 禁止连续两次转动同一个面。

## 顺时针的定义
在该面的正前方，正对着它看时的顺时针方向：
- U：从上往下看是顺时针
- D：从下往上看是顺时针
- 其余四面：从该面外侧看是顺时针

## 面与面的关系
F 的对面是 B，U 的对面是 D，L 的对面是 R。

## 项目结构（一层层是什么）

```
src/
├── core/      魔方逻辑本身（纯数据计算，禁止引入 three）
├── render/    3D 画面（唯一允许用 three 的地方）
├── ui/        12 个转动按钮等界面控件
└── main.ts    把上面三层接起来的"接线员"
```

一条铁律：**逻辑与画面分离**——画面只能读逻辑的数据，永远不能反过来改它。
这条规矩有专门的测试盯着（`src/core/separation.test.ts`）。

逐文件的详细说明（谁依赖谁、每个文件干什么）：见 [docs/architecture.md](docs/architecture.md)。
